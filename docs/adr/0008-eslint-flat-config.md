# 0008 — ESLint flat config

## Status
Accepted

## Context
Next.js 16 ships `eslint-config-next` in flat-config form by default, and the `next lint` command has been removed in favor of the plain ESLint CLI.

## Decision
Use `eslint.config.mjs` (flat config) as generated by `create-next-app`, and run it via `npm run lint` → `eslint`, not `next lint`.

## Rationale
- Matches the framework's own default and avoids fighting an unsupported legacy `.eslintrc` format.
- Keeps linting decoupled from the Next.js CLI, consistent with `next build` no longer running lint itself.

## Consequences
- New ESLint plugins/rules must be added in flat-config array form (`defineConfig([...])`), not legacy `extends` strings.
