# Performance Skill

## Rules
- Prefer Server Components.
- Fetch data close to where it is rendered.
- Use `next/image`.
- Avoid unnecessary client-side JavaScript.
- Avoid fetching the same data repeatedly.
- Paginate product/order lists when needed.
- Add database indexes for real query patterns.
- Keep checkout reliable before optimizing micro-performance.

## Measure
Check:
- initial page load
- product listing performance
- image sizes
- client bundle size
- database query count
- checkout latency
