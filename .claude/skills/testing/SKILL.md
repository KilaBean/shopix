# Testing Skill

## Vitest
Use for:
- cart calculations
- money calculations
- validation schemas
- order totals
- payment state transitions
- webhook signature logic
- idempotency helpers

## Playwright
Cover the most important user journeys:
1. Browse products
2. Add product to cart
3. Update cart
4. Sign in
5. Start checkout
6. Complete a mocked/test payment flow
7. View order confirmation
8. View order history
9. Admin product management

## Rule
Do not aim for meaningless 100% coverage. Prioritize business-critical paths, especially payment and authorization.
